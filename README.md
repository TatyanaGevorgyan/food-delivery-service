# Food Delivery Service



Console application for ordering food, written in Java 17 with Maven.



## Features

\- Customer authentication

\- Browsing foods and managing a shopping cart

\- Balance check and order creation

\- Data loaded from and saved to CSV files



## Structure

\- domain - Customer, Food, Cart, Order, OrderItem

\- service - business logic and custom exceptions

\- data - CSV readers and writer, DataStore interface

\- view - user interface interface



## Run

mvn clean install
